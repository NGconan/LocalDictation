# LocalDictation

A local-first macOS voice dictation tool powered by Whisper.

Press a hotkey, speak, transcribe locally, and paste the result anywhere.

## Features

- Local speech-to-text
- Whisper powered
- Privacy first
- Hotword correction
- Optional local LLM polishing
- No subscription required
